# zusbml: Read, Write and Derive Equations from 'SBML' Models

Reads Systems Biology Markup Language ('SBML') core documents, Level 3
Versions 1 and 2 and Level 2 Versions 4 and 5, into one R object, writes
that object back as Level 3 Version 2, and derives from it the states,
right-hand sides, assignments and events an ordinary differential
equation solver needs, following the specification at
<https://sbml.org/documents/specifications/>.
